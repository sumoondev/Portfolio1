# Portfolio1
A simple interactive 3d portfolio using Blender and Godot, designed to run on web browsers.

---

## Tech Stack & Setup used

* **Engine:** Godot 4.7.2
* **3D Modeling:** Blender 5.1.0

### Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/sumoondev/Portfolio1.git
   ```
2. Open **Godot Engine 4.7+**.
3. Import `project.godot`.
4. Ensure the build target renderer is set to **Compatibility**.
5. Run the main scene `scenes/main.tscn`.
